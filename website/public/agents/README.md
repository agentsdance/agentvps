# Agent brand assets

These marks identify the products linked in the AgentVPS MCP client list.
They do not imply sponsorship or individual end-to-end certification.
Product names and trademarks belong to their respective owners.

Assets are served locally, with original shapes and colors preserved.
Codex and Claude Code use the dedicated product marks from Lobe Icons
(pinned revision in sources.json), not Unicode substitutes or generic icons.
Their MIT notice is in Lobe-Icons-LICENSE. GitHub Copilot uses the official
Primer Octicon; its MIT notice is in Octicons-LICENSE. Other images come from
the products' official sites. sources.json records every download URL.
