01

在 VPS 上安装。

通过 SSH 登录你要交给智能体使用的 VPS，运行：

VPS 终端
curl -fsSL https://agentvps.ai-infra.org/install.sh -o install-agentvps.sh
sudo bash install-agentvps.sh

安装 0.0.1 版本，包含 CLI、后台服务、Chromium 和 Linux 桌面。下载的安装包会通过预设 SHA-256 校验。 查看安装脚本 ↗

02

打开你的远程电脑。

在 VPS 防火墙中放行 TCP 8080 端口，然后打开 http://YOUR_VPS_IP:8080。在 VPS 终端读取访问令牌，粘贴到登录界面：

VPS 终端
sudo cat /var/lib/agentvps/token

请妥善保管令牌。公网 IP 访问使用 HTTP；处理私人内容时，请使用 HTTPS 或 SSH 转发。需要分享网页预览时，可额外开放 8081 端口。

03

连接你的智能体。

在运行智能体的电脑上，使用 Node.js 22 或更新版本安装客户端：

运行智能体的电脑
npm install -g https://github.com/agentsdance/agentvps/releases/download/v0.0.1/agentsdance-agentvps-0.0.1.tgz

通过 SSH 复制令牌，然后连接。请将 YOUR_VPS_IP 换成你的 VPS IP；如果 SSH 用户名不同，也请替换 ubuntu：

运行智能体的电脑
mkdir -p ~/.config/agentvps
umask 077
ssh ubuntu@YOUR_VPS_IP 'sudo cat /var/lib/agentvps/token' > ~/.config/agentvps/vps.token
agentvps connect --url http://YOUR_VPS_IP:8080 --token-file ~/.config/agentvps/vps.token
agentvps status
codex mcp add agentvps -- agentvps mcp

最后一行用于注册 Codex。连接 Claude Code 或其他 MCP 客户端时，使用命令 agentvps，参数为 ["mcp"]。 查看连接配置 ↓

01 / 检查

确认一切就绪。

VPS
sudo agentvps status
sudo agentvps call health_check '{"browser":true}'

检查工作空间标识与各项功能。服务正在运行，并不代表浏览器和桌面已正常工作。

02 / 升级

升级，保留文件。

下载新版本安装包，然后运行：

VPS
sudo agentvps upgrade ./agentsdance-agentvps-VERSION.tgz

文件、浏览器配置和服务配置会保留。重启时，运行中的命令和应用窗口会关闭。早期未使用 @agentsdance scope 的安装，请先重新运行安装脚本完成迁移。

03 / 卸载

按你的需要卸载。

VPS
agentvps uninstall --dry-run
sudo agentvps uninstall

默认保留数据。只有确定要永久删除工作空间和凭据时，才添加 --purge。

使用前了解

你可能想知道。

现在已经是能自主工作的个人智能体了吗？

0.0.1 版本提供远程电脑和工具层，需要连接 Codex、Claude Code 或其他智能体来操作。内置对话和模型驱动的智能体循环仍在规划中。

能看到智能体的所有操作吗？

浏览器和原生桌面操作会实时显示在桌面上。后台 Shell 任务显示在 Commands 中，API 终端会话显示在 Remote desk 中。如果希望看到命令逐步输入，请让智能体使用原生终端。

我接管之后会怎样？

你可以用鼠标和键盘控制桌面。交还控制前，智能体无法发起新的浏览器和桌面修改操作。后台任务与已经开始的操作会继续运行。

重启后，哪些内容会保留？

工作空间文件、笔记、定时任务、已完成任务记录和 Chromium 配置会保留。运行中的命令、终端会话、应用窗口和预览链接不会保留。仅断开桌面查看器时，远程应用仍会继续运行。

它与 VPS 上的其他内容隔离吗？

AgentVPS 以一个非特权 Linux 用户运行，面向单一所有者使用，不提供多租户沙箱隔离。命令拥有该系统用户的权限。工具调用和桌面访问都需要身份认证。

启动失败，该从哪里排查？

运行 sudo systemctl status agentvps 和 sudo journalctl -u agentvps -n 50，检查云防火墙是否开放 8080 端口，再运行上面的健康检查。 提交问题 时请附上版本和错误详情，不要包含令牌。
